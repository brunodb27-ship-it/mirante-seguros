# Mirante · mercado segurador

Comparativo do mercado segurador brasileiro com dados públicos da SUSEP (SES) e notícias, atualizado sozinho todo dia.

- **Dados da SUSEP:** o robô confere a base completa do SES todo dia e só baixa de novo quando a SUSEP publica uma versão nova.
- **Notícias:** buscadas todo dia no Google Notícias para os maiores grupos.
- **Nomes dos grupos e termos de busca:** edite `pipeline/nomes.txt`.

Painel independente, sem vínculo com a SUSEP ou com qualquer seguradora.
